# randomPasswordGenerator 🔐

A site that generates random passwords that are difficult to hack

> Never use a simple password again.

**RandomPasswordGeneratos** is a website made for your ciber security safety!

## 🛠 Built With <a name="built-with"></a>

#### - HTML 
#### - CSS
#### - Vanilla JavaScript

### Setup

Clone this repository to your desired folder, open with live server and you are good to go!

[This github repo](https://github.com/memelopez/randomPasswordGenerator)
